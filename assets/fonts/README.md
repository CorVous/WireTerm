# Bundled extension font

`Inter.ttf` is the Inter variable upright font distributed by the Google Fonts
repository for the Inter Project. It is bundled and embedded under the SIL Open
Font License 1.1 in `OFL.txt`.

- Source: `https://github.com/google/fonts/tree/main/ofl/inter`
- Inter.ttf SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`
- OFL.txt SHA-256: `5b9321a4298cfeb6b34354164a1c3afc3db114569984c502b9b35d988fd58c57`

WireTerm embeds these exact bytes in the executable and does not discover
system fonts for Extension rendering.
